## Honest limitations
Chrome and Edge ZIPs are unpacked desktop extensions, not pre-approved or signed store installers. Native HLS/DASH assembly needs user-installed Python, FFmpeg/FFprobe, and Native Messaging registration. VSIX is manually installable, with separate Marketplace / Open VSX approval. DRM circumvention is unsupported. No browser store or VS Code Marketplace approval is asserted by this repository.
